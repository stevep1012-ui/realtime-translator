# 실시간번역기 (macOS / Windows / 모바일)

Teams·Zoom·YouTube 등 컴퓨터 스피커로 나오는 말을 인식해 번역 자막을 항상 위에 띄웁니다.
영어·일본어 등 화자 언어는 자동 감지됩니다. 자막은 같은 폴더에 자동 저장됩니다.

## 모바일 (설치 없음)
폰 브라우저에서 열기 → **https://stevep1012-ui.github.io/realtime-translator/**
- 마이크로 주변 말을 듣습니다 (대면 회의, 스피커폰, 노트북 스피커 옆)
- 첫 실행 시 API 키 2개 입력. 홈 화면에 추가하면 앱처럼 사용
- 폰은 다른 앱(Teams)의 소리를 직접 잡을 수 없습니다. 그 용도는 아래 데스크톱 버전

## 데스크톱 다운로드
이 페이지 상단 초록색 **Code → Download ZIP** → 압축 해제 → 아래 3단계

## 시작하기 (3단계)

1. 이 폴더를 원하는 곳에 둔다
2. **Windows: `실행.bat`** / **Mac: `실행.command`** 더블클릭
   - Python 등 필요한 프로그램이 없으면 자동으로 설치됩니다 (인터넷 필요, 1~5분)
   - Mac 은 중간에 Mac 암호를 묻고, 한 번 재시작 후 다시 더블클릭해야 합니다
3. 처음 실행 시 **설정 창**이 뜨면 API 키 2개를 넣고 "저장하고 시작"
   - OpenAI 키: 창의 "키 발급 페이지" 버튼 → 로그인 → Create new secret key
   - Anthropic 키: 창의 "키 발급 페이지" 버튼 → 로그인 → Create Key
   - 두 서비스 모두 결제 카드 등록과 소액 충전($5 정도)이 필요합니다. 1시간 회의 ≈ 500~1,000원

이후에는 실행 파일 더블클릭만 하면 바로 자막창이 뜹니다.

## 보안 경고가 뜰 때
- Windows "PC 보호" → **추가 정보 → 실행**
- Mac "확인되지 않은 개발자" → 파일 **우클릭 → 열기**

## Mac 만 한 번 필요한 설정
실행 중 안내가 나오면 [오디오 MIDI 설정] 창에서:
1. 왼쪽 아래 `+` → **다중 출력 장치 생성**
2. `BlackHole 2ch` + 실제 쓰는 스피커/헤드셋 체크
3. 시스템 설정 → 사운드 → 출력 → **다중 출력 장치**
   (Teams/Zoom 은 앱 안의 스피커 설정도 다중 출력 장치로)

회의 후 볼륨 키가 안 먹으면 출력을 원래 스피커로 되돌리면 됩니다.

## 사용
- 자막창: 번역문(큰 글씨) + 원문(작은 회색). 말이 끊기면 원문이 먼저 뜨고 1~2초 뒤 번역
- 창 닫기(✕)로 종료. 자막은 `실시간번역기_날짜_시각.txt` 로 저장됨 (10초마다 중간 저장)
- Windows 는 기본 스피커 소리를 잡습니다. Teams 스피커를 헤드셋으로 바꾸면 Windows 기본 출력도 같은 장치로

## 언어 / 세부 설정
폴더의 `.env` 파일을 메모장으로 열어 수정 (`.env.example` 에 항목 설명)
```
SOURCE_LANG=          # 비우면 자동 감지. 한 언어로 고정: en, ja, zh, de, fr, es …
TARGET_LANG=한국어     # 자막 언어
```
키를 다시 입력하려면 `.env` 를 지우고 실행하면 설정 창이 다시 뜹니다.

## 문제 해결 (검은 터미널 창의 메시지 기준)
- `[STT 오류]` → `.env` 에 `STT_MODEL=whisper-1` 한 줄 추가
- `[번역 오류] 401` → Anthropic 키 확인 / `insufficient` → 크레딧 충전
- `[stt]` 가 아예 안 찍힘 → Mac: 사운드 출력이 다중 출력 장치인지 / Windows: 소리가 기본 스피커로 나오는지 확인
- 자동 감지가 엉뚱한 언어로 인식하면 `.env` 에 `SOURCE_LANG=en` 처럼 고정
